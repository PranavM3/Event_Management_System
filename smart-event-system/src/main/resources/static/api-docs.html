📚 API Documentation

Complete REST API reference for Smart Event Registration System

🔐 Authentication

POST /api/auth/signup Public
Register a new user account. Default role is USER if not specified.
Request Body:
{
  "firstName": "John",
  "lastName": "Doe",
  "email": "john@example.com",
  "password": "password123",
  "phone": "1234567890",
  "roles": ["user"]  // Options: user, organizer, admin
}
cURL Command:
curl -X POST http://localhost:8080/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "firstName": "John",
    "lastName": "Doe",
    "email": "john@example.com",
    "password": "password123",
    "phone": "1234567890",
    "roles": ["user"]
  }'
POST /api/auth/signin Public
Login with email and password. Returns JWT token for authentication.
Request Body:
{
  "email": "john@example.com",
  "password": "password123"
}
Response:
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "id": 1,
  "email": "john@example.com",
  "firstName": "John",
  "lastName": "Doe",
  "roles": ["ROLE_USER"]
}
cURL Command:
curl -X POST http://localhost:8080/api/auth/signin \
  -H "Content-Type: application/json" \
  -d '{
    "email": "john@example.com",
    "password": "password123"
  }'

📅 Events

GET /api/events 🔒 Auth Required
Get all events. Supports pagination and filtering.
cURL Command:
curl -X GET http://localhost:8080/api/events \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
GET /api/events/{id} 🔒 Auth Required
Get a specific event by ID.
cURL Command:
curl -X GET http://localhost:8080/api/events/1 \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
POST /api/events 🔒 Auth Required (ORGANIZER/ADMIN)
Create a new event. Requires ORGANIZER or ADMIN role.
Request Body:
{
  "name": "Tech Conference 2025",
  "description": "Annual technology conference",
  "location": "Convention Center",
  "startDate": "2025-12-01T09:00:00",
  "endDate": "2025-12-01T17:00:00",
  "capacity": 500,
  "category": "CONFERENCE"
}
cURL Command:
curl -X POST http://localhost:8080/api/events \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Tech Conference 2025",
    "description": "Annual technology conference",
    "location": "Convention Center",
    "startDate": "2025-12-01T09:00:00",
    "endDate": "2025-12-01T17:00:00",
    "capacity": 500,
    "category": "CONFERENCE"
  }'
PUT /api/events/{id} 🔒 Auth Required (ORGANIZER/ADMIN)
Update an existing event.
cURL Command:
curl -X PUT http://localhost:8080/api/events/1 \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated Event Name",
    "description": "Updated description",
    "location": "New Location",
    "startDate": "2025-12-01T09:00:00",
    "endDate": "2025-12-01T17:00:00",
    "capacity": 600,
    "category": "CONFERENCE"
  }'
DELETE /api/events/{id} 🔒 Auth Required (ORGANIZER/ADMIN)
Delete an event.
cURL Command:
curl -X DELETE http://localhost:8080/api/events/1 \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

✅ Registrations

POST /api/registrations 🔒 Auth Required
Register for an event.
Request Body:
{
  "eventId": 1
}
cURL Command:
curl -X POST http://localhost:8080/api/registrations \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "eventId": 1
  }'
GET /api/registrations/my-registrations 🔒 Auth Required
Get all registrations for the current user.
cURL Command:
curl -X GET http://localhost:8080/api/registrations/my-registrations \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
PUT /api/registrations/{id}/cancel 🔒 Auth Required
Cancel a registration.
cURL Command:
curl -X PUT http://localhost:8080/api/registrations/1/cancel \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

💬 Feedback

POST /api/feedback 🔒 Auth Required
Submit feedback for an event.
Request Body:
{

  "comment": "Great event! Well organized."
}
cURL Command:
curl -X POST http://localhost:8080/api/feedback \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "eventId": 1,
    "rating": 5,
    "comment": "Great event! Well organized."
  }'
GET /api/feedback/event/{eventId} 🔒 Auth Required
Get all feedback for a specific event.
cURL Command:
curl -X GET http://localhost:8080/api/feedback/event/1 \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

🔑 Using JWT Authentication

After logging in, you'll receive a JWT token. Include this token in the Authorization header for all protected endpoints:

Authorization: Bearer YOUR_JWT_TOKEN_HERE

Example Workflow:

  1. Register: POST to /api/auth/signup
  2. Login: POST to /api/auth/signin (save the token)
  3. Use Token: Add "Authorization: Bearer {token}" header to all requests
  4. Access Protected Resources: Make requests to events, registrations, etc.
